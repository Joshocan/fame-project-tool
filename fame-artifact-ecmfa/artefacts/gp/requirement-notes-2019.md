# Requirement notes, 2019

R-14  Every laboratory request must carry an order identifier drawn from the
      practice numbering scheme. The scheme is documented only here; it does
      not appear in the API documentation.

R-19  The authorising party on a request is a *practitioner* in the sense of
      a physician with prescribing rights. Nursing staff may record but not
      authorise.

R-22  The requested tests on an order are drawn from the practice catalogue.
