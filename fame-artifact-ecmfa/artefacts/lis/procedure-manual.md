# Laboratory procedure manual (extract)

## 4.2 Release of results

A validated test is released to the ordering system as final. Once released
it is a complete, reportable artefact in its own right and may not be
amended except by formal correction procedure.

> NOTE. This description is in tension with the HL7 interface specification,
> which treats the same information as one segment of a result message
> rather than as a standalone document. The two sources disagree on whether
> the model should contain one concept or two. This is recorded in the model
> as a *contradicting* provenance link on `ValidatedTest`, which caps its
> confidence under condition C2.
